# 🍽️ FlavourlyAI – AI Inspired Digital Recipe Management System

FlavourlyAI is a full-stack web application designed to simplify recipe discovery, creation, management, and organization. It provides users with a centralized digital cookbook featuring recipe management, AI-assisted recipe generation, nutrition information, favorites, and community reviews.

## 🚀 Key Features

- **User Authentication:** Secure registration, login, logout, and session management.
- **Dashboard:** Personalized dashboard for accessing application features.
- **Recipe Management:** Create, view, edit, and delete recipes with images, ingredients, and cooking instructions.
- **AI Recipe Generator:** Generate recipe suggestions based on user prompts.
- **Favorites:** Save and manage favorite recipes.
- **Nutrition Dashboard:** View recipe-related nutritional information.
- **Reviews & Ratings:** Add, edit, and delete reviews with rating statistics.
- **Profile Management:** Manage user profile information.
- **User Settings:** Customize notification preferences, privacy, and recipe display preferences.

## 🏗️ Application Architecture

FlavourlyAI follows a layered MVC-inspired architecture:

- **Presentation Layer:** JSP, HTML, CSS and JavaScript.
- **Controller Layer:** Java Servlets handle HTTP requests and application workflows.
- **Service Layer:** Handles application business logic.
- **Data Access Layer:** DAO classes manage database operations using JDBC.
- **Database Layer:** MySQL stores users, recipes, reviews, favorites, and settings.

## ⚙️ Installation & Setup

### Prerequisites

- Java JDK
- Eclipse IDE for Enterprise Java and Web Developers
- Apache Tomcat 9
- MySQL Server
- MySQL Workbench

### Steps

1. Clone the repository:

   ```bash
   git clone https://github.com/gauridyappa/FlavourlyAI.git
   ```

2. Import the project into Eclipse as an existing project.

3. Configure Apache Tomcat 9 in Eclipse.

4. Create the MySQL database using the project's SQL schema.

5. Configure the database connection in the application.

6. Add the MySQL JDBC driver if it is not already included.

7. Run the project on Apache Tomcat.

8. Open the application in your browser.
